    Module electron/bridge-contract

    Shared IPC contract for the Electron native shell.

    The renderer talks to one BrowserXmppRuntimeBridge living in the main process. Everything that is not an event subscription is a plain method call; a small set of getters must remain synchronous because the existing React hooks read them during render.
